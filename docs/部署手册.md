## 一、系统架构总览

```
                    ┌─────────────────────────────────────────┐
  7 个容器服务       │  MySQL(元数据) → Metastore → HiveServer2 │
                    │  ClickHouse(OLAP加速)  Superset(BI)      │
                    │  Streamlit App(NL2SQL问答)               │
                    └─────────────────────────────────────────┘
数据流：CSV → ODS → 清洗 → DWD → DWS → ADS（Hive 四层）
                                  ↓          ↓
                            Superset 仪表板  ECharts 大屏 / Streamlit 问答
```

| 服务 | 端口 | 用途 |
|---|---|---|
| hive-mysql | 3307→3306 | Metastore 元数据库（MySQL 8.0） |
| hive-metastore | 9083 | Hive 元数据服务 |
| hive-hiveserver2 | 10000 / 10002 | Hive SQL 引擎 / Web UI |
| hive-clickhouse | 8123 / 9000 | ADS 指标 OLAP 加速层（24.8） |
| hive-superset | 8088 | BI 仪表板（4.1.1） |
| hive-streamlit-app | 8501 | NL2SQL 智能问答（Streamlit） |

## 二、一键部署

```bash
# 1. 准备环境文件
cp .env.example .env
# 编辑 .env：填入 LLM_API_KEY、SUPERSET_SECRET_KEY 等（.env 已被 .gitignore 排除）

# 2. 准备 MySQL JDBC 驱动（必须，否则 Metastore 无法启动）
#    下载 mysql-connector-j-8.0.33.jar 放入 ./lib/ 目录

# 3. 一键启动全部服务（自动按依赖顺序：mysql → metastore → hiveserver2 → 下游）
docker compose up -d

# 4. 查看健康状态（全部 healthy 即部署成功）
docker compose ps
```

- `metastore` 依赖 `mysql` healthcheck（mysqladmin ping）

## 三、密钥安全管理

1. **集中管理**：全部敏感信息（MySQL/ClickHouse 密码、Superset SECRET_KEY、LLM API Key）统一放根目录 `.env`，`docker-compose.yml` 中仅以 `${VAR:-默认值}` 引用
2. **不入版本库**：`.gitignore` 排除 `.env`；仓库提供 `.env.example` 模板（仅占位符）
3. **不入镜像**：`.dockerignore` 排除 `**/.env`，镜像内无明文密钥
4. **权限最小化**：Superset 数据源按库授权；ClickHouse 单独密码；NL2SQL Prompt 三防线 + 只读校验（写请求直接拦截）
5. **密钥轮换**：LLM API Key 在智谱控制台轮换后，只需更新 `.env` 中 `LLM_API_KEY` 并 `docker compose up -d app` 重启容器

## 四、查询优化与压力测试

### 优化实验（见 sql/optimize/08_query_optimize.sql）

| 实验 | 写法 A | 写法 B | 结论 |
|---|---|---|---|
| 分区裁剪 | `SUBSTR(order_timestamp,1,7)='2024-11'` 全表扫 366 分区 | `order_date BETWEEN ...` 仅扫 30 分区 | 小数据量下收益 ~6%；分区键过滤是强制规范 |
| 数据倾斜 | 直接 GROUP BY user_id | 加盐两阶段聚合 | 头部用户长尾规避（大数据量下收益显著） |
| 预聚合加速 | dwd 明细实时聚合 | ads ORC 预聚合表 | ADS 层命中即提速（压测 avg 4.62s vs 5.69s/6.08s） |

### 压测结果（scripts/stress_test.py，4 并发 × 5 轮）

| 查询 | min | avg | P50 | P95 | max | 失败 |
|---|---|---|---|---|---|---|
| ads 预聚合（ORC 366 行） | 3.63s | 4.62s | 4.82s | 5.01s | 5.01s | 0 |
| 明细聚合（分区裁剪） | 3.79s | 5.69s | 6.04s | 6.45s | 6.45s | 0 |
| 明细聚合（全表扫描） | 4.81s | 6.08s | 6.26s | 6.70s | 6.70s | 0 |

## 五、部署踩坑记录（重要）

| 问题 | 根因 | 解决 |
|---|---|---|
| Metastore 重启循环 `ClassNotFoundException com.mysql.cj.jdbc.Driver` | 从新目录运行 compose 时挂载源 `./lib/*.jar` 不存在，Docker 自动建了空目录 | 把 jar 复制到 `./lib/` 后 `--force-recreate`。教训：bind mount 源必须预先存在 |
| ClickHouse 401/认证失败 | `CLICKHOUSE_PASSWORD` 为空时镜像行为不确定 | 显式设置非空密码 |
| 容器内 `import thrift_sasl` 失败 | `sasl` 包含 C 扩展编译失败 | 用 `pure-sasl` 替代（纯 Python SASL） |
| Superset 地图不显色 | 内置 GADM 中国地图用英文省名（`NAME_1`），数据是中文省名 | 建映射虚拟数据集（CASE WHEN → Guangdong 等） |
| Hive TSV 导出 JSON 含科学计数法字符串 | beeline tsv2 对大 double 输出 `3.6E7` 格式 | 导出转换脚本统一 `float()` 解析 |
| Streamlit 容器无法执行 `docker exec` beeline | 容器内无宿主机 Docker | nl2sql 增加 `HIVE_URI` 环境变量，切 pyhive 直连 Thrift 协议 |
