# 指标定义文档（口径统一）

> 项目：云购生活新零售　团队：云购数智队　版本：v1.0（第 3 周）　日期：2026-11-09
> 目的：所有 DWS/ADS 层指标计算以本文档为唯一口径来源，避免"数出多门"。

## 一、指标口径总表

| 指标 | 英文/字段名 | 口径定义 | 计算公式 | 数据范围 |
|---|---|---|---|---|
| GMV | `gmv` | 有效订单实付金额之和 | `SUM(pay_amount)` | `dwd_order` 全量（已清洗） |
| 订单量 | `orders` | 去重订单数 | `COUNT(DISTINCT order_id)` | 同上 |
| 客单价 | `aov` | 平均每单实付金额 | `GMV ÷ 订单量` | 同上 |
| 活跃用户数 | `active_users` | 统计周期内有下单行为的去重用户数 | `COUNT(DISTINCT user_id)` | 同上 |
| 复购率 | `repurchase_rate` | 下单 ≥2 次用户占下单用户比例 | `下单≥2次用户数 ÷ 下单用户数` | 同上 |
| 优惠金额 | `discount` | 订单优惠金额之和 | `SUM(discount_amount)` | 同上 |
| 折扣率 | `discount_rate` | 优惠占应付比例 | `优惠 ÷ (实付 + 优惠)` | 同上 |
| ARPU | `arpu` | 每用户平均消费 | `GMV ÷ 活跃用户数` | 同上 |
| 品类销售占比 | `sales_pct` | 品类销售额 ÷ 全部销售额（基于明细金额相对占比） | 见《探索性分析简报》数据局限声明 | `dwd_order_item` |
| 履约率 | `fulfillment_rate` | 已完成订单占比 | `已完成订单 ÷ 订单量` | 同上 |

## 二、口径说明与边界（重要）

1. **"有效订单"的定义**：`dwd_order` 即清洗后的有效订单——已剔除 601 条金额异常与 600 条重复记录（第 2 周清洗），未再叠加状态过滤。取消/退款订单**计入 GMV**（实付口径），其占比单独用履约率指标呈现，不做双重扣除。
2. **GMV 分歧的处理**：明细表 `item_amount` 合计与订单表 `pay_amount` 合计不勾稽（源数据独立生成），**绝对金额一律以 `dwd_order.pay_amount` 为准**；品类结构分析只使用 `dwd_order_item` 的相对占比。
3. **复购率的本数据集局限**：模拟数据中 1,000 名用户均下单 ≥4 次，复购率恒为 100%，该指标在本数据集**无区分度**，仅保留口径定义与计算链路，不用于业务结论。
4. **时间口径**：统计周期以 `order_date`（订单日期）为准，分区字段同名；月度维度取 `substr(order_date,1,7)`。
5. **维度口径**：区域维度以 `dim_store.province`（门店归属）或 `dim_user.province`（用户归属）区分——区域分析统一采用**用户归属**口径，与第 2 周简报保持一致；门店排行采用门店归属。
6. **用户价值分层**：按 2024 全年累计消费金额五等分（NTILE），R5 最高；分层依据消费金额单一维度，不引入 RFM 三维（行为数据与订单数据无会话关联，R/F 维度不可信）。
