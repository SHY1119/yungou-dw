### 会员等级贡献

**关键发现（本周最重要结论）**：四个等级的 ARPU 分别为 36,225 / 36,142 / **36,791** / 35,851，极差仅 **2.62%**，且**普通会员的 ARPU 最高**。等级越高消费并未越高，会员体系与消费金额**不存在正相关**。

这说明当前会员分层是「按注册时长/累计积分标签化」而非「按消费能力分层」，权益设计未能撬动高等级用户的额外消费。**建议**：会员权益应从"身份象征"转向"阶梯返利"，让等级提升直接对应价格优惠，否则等级只增加运营成本、不产生增量 GMV。

## 十、核心结论（6 条）

1. **经营基本盘健康但缺乏增长引擎**：全年 GMV ¥3,626 万、客单价 ¥2,518、月度波动仅 11.5%，说明存量运营稳定；但品类无爆品（CR1 14.95%）、区域无高地（首末位仅差 1.67 倍）、渠道无强势端（四渠道均 25%），缺乏可放大的增长抓手。

2. **19.28% 订单未正常履约，是最优先的改善项**：已取消 13.86% + 退款中 5.42%。若将取消率压到行业 5% 的水平，按现有客单价可挽回约 ¥3,100 万 × 8.86% ≈ **¥275 万 GMV**。建议优先排查支付环节与库存准确性。

3. **会员体系未产生分层价值**：四等级 ARPU 极差仅 2.62%，普通会员 ARPU 反而最高。等级与消费能力脱钩，权益设计需要重构为阶梯返利。

4. **区域增长应靠拉新而非提客单**：各省客单价极差仅 5%（2,451~2,575），GMV 差异完全由用户数驱动。陕西 79 人贡献 286.7 万，湖北 49 人贡献 171.7 万，两者客单价几乎相同。

5. **APP 存在高客单商品推荐的机会**：APP 订单量最大（3,705）但客单价最低（2,492.60），PC 官网客单价最高（2,537.36）。同样的用户在不同端表现出的客单差异，指向 APP 端商品推荐偏低价段。

6. **绍兴旗舰店值得做样本复盘**：订单量仅第 2，客单价比均值高 8.8%，说明其品类组合能有效拉升单笔金额，是门店调优的现成模板。

## 十一、数据局限性声明

本简报所有结论建立在模拟数据集之上，以下限制需在引用时注意：

| 限制 | 影响 | 处理方式 |
|---|---|---|
| 明细金额与订单金额不勾稽（6,777 万 vs 3,626 万） | 品类分析只能看相对占比 | 品类结论仅用占比，绝对 GMV 以订单表为准 |
| 1,000 名用户全部下单 ≥4 次，复购率 100% | 无法做新老客分层、复购周期分析 | 未输出相关结论，避免过度解读 |
| 行为数据与订单数据独立生成 | 无法计算真实转化漏斗 | 仅将行为数作为热度信号 |
| 品类件均价趋同（4,280~4,347） | 难以支撑品类定价策略分析 | 明确标注为数据特征而非业务结论 |
| 单分区仅约 39 行 | 按天分区存在小文件问题 | 已在架构文档记录，第 3 周评估改为按月分区 |
