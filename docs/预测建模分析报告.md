# 预测建模分析报告：每日 GMV 时间序列

> 项目：云购生活新零售　团队：云购数智队　成员：孙浩瑜　日期：2026-11-09
> 数据源：`ydsh_dws.dws_trade_day`（366 天，2024-01-01 ~ 2024-12-31，从 Hive 导出至 `data/dws_trade_day.tsv`）
> 建模脚本：`scripts/forecast_gmv.py`　图表：`docs/images/gmv_forecast.png`

## 一、任务与结论摘要

任务：对每日 GMV 做趋势/季节分析，用 scikit-learn 系模型预测未来 7 天 GMV，并评估模型适用边界。

**核心结论：**

| 项目 | 结果 |
|---|---|
| 最优模型 | LinearRegression（滞后特征 + 星期），测试集 **MAPE 13.89%** |
| 朴素基线（明天=昨天） | 测试集 MAPE 23.02% |
| 相对提升 | 误差降低 **39.7%** |
| XGBoost | 测试集 MAPE 15.09%，**过拟合**（训练 6.84%），弃用 |
| 未来 7 天 GMV 预测 | **约 69.0 万元**（690,182 元；近 7 天实际 65.98 万元） |
| 模型可用边界 | 仅适用于**平稳期短期（≤7 天）均值预测**，不适用于趋势拐点与大促脉冲预测 |

## 二、时间序列结构分析

### 2.1 统计特征

| 特征 | 数值 | 含义 |
|---|---|---|
| 日 GMV 均值 | 99,061 元 | — |
| 标准差 | 18,531 元 | — |
| 变异系数 CV | 0.187 | 波动温和，属于低波动序列 |
| 极值 | 50,273 ~ 156,211 元 | 最大值约为最小值 3.1 倍 |
| 线性趋势斜率 | **−6.75 元/天**（年化 −0.2 万元） | 全年基本零趋势 |

### 2.2 趋势与季节性判定

1. **无有效趋势**：全年线性斜率 −6.75 元/天，在 18,531 元的日波动面前可以忽略。业务上对应"存量平稳经营、无增长引擎"的判断（与探索性分析简报结论一致）。
2. **星期效应微弱**：七个 weekday 的日均 GMV 在 95,455 ~ 102,166 元之间，极差 7.0%，不构成可利用的周内周期。
3. **月度波动有业务含义但幅度有限**：2 月（−7.77%，春节）与 6 月（−8.21%，618 前蓄水）为低谷，12 月 +3.99% 回升。月度环比全部落在 ±9% 以内，**无大促脉冲形态**。
4. **序列本质**：围绕约 9.9 万元的日均值做随机波动，接近**白噪声叠加弱噪声水平漂移**。这一结构决定了预测模型的上限：可预测成分只有"均值回归"，日与日之间的真实相关性很低。

### 2.3 移动平均

7 日移动平均将日波动方差压缩约 6 倍（标准差从 18,531 降至约 6,800 元），30 日移动平均进一步平滑为 283.9 万 ~ 316.6 万的月度水位线。MA 曲线确认了"平稳"判断——两条均线全年横向运行，无持续发散。

## 三、预测模型构建与评估

### 3.1 方法设计

- **特征**（全部只使用预测时点之前的信息，防止未来信息泄漏）：滞后 1/2/7/14 天 GMV、截至昨日的 7 日与 30 日均值、星期几（类别特征）。
- **切分方式**：按时间顺序前 80% 训练（1/31~10/24，268 天）、后 20% 测试（10/25~12/31，68 天）。**禁止随机打乱**——时序数据的随机切分会让测试集"看到"训练集的未来，产生虚高精度。
- **对照模型**：
  - 朴素基线 naive lag1（明天 = 昨天）：任何模型必须先赢过它才有存在价值；
  - LinearRegression：平稳序列上的首选，方差低、可解释；
  - XGBoost：非线性对照，检验是否存在可挖掘的交互结构。

### 3.2 评估结果（测试集，68 天）

| 模型 | MAE（元） | MAPE | 训练集 MAPE | 判定 |
|---|---|---|---|---|
| 朴素基线 lag1 | 21,691 | 23.02% | — | 参照 |
| **LinearRegression** | **13,671** | **13.89%** | 16.08% | **采用**（测试误差 < 训练误差，无过拟合迹象） |
| XGBoost | 14,931 | 15.09% | **6.84%** | 弃用（训练/测试误差差 2.2 倍，过拟合） |

三点解读：

1. **线性模型比基线误差低 39.7%**：提升主要来自"多天滞后均值"对单日随机波动的平滑——模型学到的主要是均值回归，而非某种真实的动态规律。
2. **XGBoost 的过拟合本身就是结论**：训练 MAPE 6.84% 看起来诱人，但测试 15.09% 劣于线性模型。它把训练期内的随机波动当成了模式。**在低信噪比平稳序列上，复杂模型不占优势**，这与时序预测文献的普遍经验一致。
3. **MAPE ≈ 13.9% 是这个序列的合理水平而非模型缺陷**：日 GMV 的不可解释随机成分（广告投放、个别大额订单等）在本数据中占比过高，任何模型的精度天花板都在这一量级。

|---|---|
| 2025-01-01 | 98,688 |
| 2025-01-02 | 99,376 |

## 四、模型适用边界（批判性审视）

以下边界决定了本模型**不能**被如何使用：

1. **不能预测拐点与脉冲**。模型本质是"平滑后的均值"，2 月春节、618 大促这类结构性波动它既学不到也预警不了。若 2025 年 1 月有促销，预测值将系统性偏低。
2. **预测步长不宜超过 7 天**。递归预测第 2 天起把预测值当输入，误差随步长累积；本序列无趋势无强周期，长步长预测会收敛到常数约 9.9 万元——那不是预测，是均值外推。
3. **精度不能对外承诺**。MAPE 13.89% 意味着单日预测误差可达 ±1.9 万元；用于备货/排班决策时必须按区间而非点值传达。
4. **数据本身的结构局限**：366 天样本无大促、无增长、无断点，模型没有机会学习非平稳模式。若业务进入增长期或营销常态化，本模型需重构（加入日历特征、促销标记，改用具备外生变量的模型）。
5. **更诚实的替代方案**：对平稳弱周期序列，直接用"近 7/30 天移动平均 + 区间"做运营参照，成本为零、可解释性 100%，模型的价值增量集中在自动化与一致性，而非精度。

```bash
# 2. 执行建模（依赖 pandas / scikit-learn / xgboost / matplotlib）
python scripts/forecast_gmv.py
```

脚本输出：结构统计、月度环比表、双模型评估（含朴素基线）、未来 7 天预测值、趋势图 `docs/images/gmv_forecast.png`、评估结果 `data/forecast_eval.csv`。随机性已固定（random_state=42），结果可精确复现。
