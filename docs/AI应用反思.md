# AI 应用反思

> 项目：云购生活新零售　团队：云购数智队　成员：孙浩瑜　日期：2026-11-09
> 范围：第 3 周三项 AI 应用实践——NL2SQL 查询接口、AI 异常归因与自动报告、AI 辅助开发全过程

## 一、本周 AI 应用的三个场景与实测表现

| 场景 | 实测表现 | 量化结果 |
|---|---|---|
| NL2SQL（GLM-4-Flash） | 初版 Prompt 7 问仅 5 过；经三轮迭代（枚举值域注入、相对时间对比示例、只读约束）后 6 问全部生成正确 SQL，1 个删除请求被正确拒绝 | SQL 正确率 71% → **100%**，安全拦截 1/1 |
| 异常归因与自动摘要 | 数字引用基本准确，但出现逻辑错误与编造 | 6 条关键表述中 2 条错误、1 条缺失，需人工修订 |
| 开发辅助（SQL/脚本/文档） | 高效但有系统性语法幻觉 | 本周记录 Hive/Spark 混用、python format 花括号注入等 5 类坑 |

## 二、三个真实失误案例（本周实测，非假设）

**案例 1：编造不存在的口径。** AI 摘要初版写出"同比增长约 3.5%"——数据只有 2024 一个自然年，根本不存在同比。模型从"全年 GMV"自动脑补了增长率。这暴露了**模型无法区分"数据中没有"和"数据为否定"**，任何统计口径类表述必须逐条核对。

**案例 2：单位与范围的悄悄偷换。** 同一份输出里，AI 先把 12 月单月 GMV（312.6 万）当成全年 GMV 引用；修正输入后，又把"月订单量 1,143 低于全年平均水平（14399）"——拿月度和全年总量比。两次错误都发生在**数字对、逻辑错**的形态，单纯"检查数字"发现不了，必须检查口径。

**案例 3：Prompt 工程的脆弱性。** 枚举值域写 `{普通会员, ...}`，被 Python 的 `str.format()` 当成占位符直接抛 KeyError——这是我自己的工程失误，但也说明 NL2SQL 系统的失败往往不在模型，而在**工程接缝处**。同样，glm-4-flash 连续三次无视"禁止在 WHERE 用 MAX()"的规则，直到我给出"错误示范 vs 正确示范"的对比后才收敛——小模型对规则列表的遵从远弱于对具体示例的模仿。

## 三、对 AI 偏见与局限的系统性认识

1. **能力边界与模型规模强相关**。glm-4-flash（免费档）与规则+few-shot 组合可以把简单查询做到 100% 正确，但复杂推理（多跳归因、口径一致性）明显吃力。生产环境应在"免费模型 + 强校验"与"付费模型 + 弱校验"之间显式权衡成本。
2. **AI 的"诚实"是有价值的**：归因环节 AI 三次声明"无直接支持数据，需补充促销/天气/竞对数据"——这与人工判断一致。说明在**明确要求引用证据**的 Prompt 约束下，模型可以做到不编造归因链，但无法约束它不编造统计口径（案例 1）。
3. **数据管道质量决定 AI 上限**。本周修复了 metastore 字符集缺陷（JDBC 缺 characterEncoding + MySQL 元数据表为 latin1），修复前 Schema 注入给模型的是 `??????`——**如果没发现这个问题，NL2SQL 的字段语义理解完全靠模型猜测字段名**。AI 应用质量的上游是数据治理，这个依赖关系容易被低估。
4. **无法把验证责任外包给 AI**。本次实践形成了固定流程：AI 生成 → 逐条对照 SQL 实查结果 → 修订版与原始版都保留、差异留痕。核验成本约为生成成本的 2~3 倍，但这是把 AI 用于经营分析的必要代价。

## 四、改进措施（已落地或列入计划）

- ✅ NL2SQL Prompt 已固化三条防线：枚举值域白名单、相对时间必须字面日期、只读约束 + 写请求显式拒绝；
- ✅ 洞察脚本加入表头过滤与"逐条核验记录表"，AI 输出与人工修订双版本留痕；
- ⬜ 计划为 NL2SQL 增加 SQL 结果行数/NULL 率的自动告警（返回 NULL 或 0 行时提示用户复核提问口径）；
- ⬜ 计划引入"双模型交叉验证"：同一问题由两个模型生成 SQL，结果不一致时降级为人工处理；
- ⬜ 密钥已通过 .env 管理（.gitignore 排除），按规范应在学期末轮换一次。

## 五、结论

本周最大的体会是：**AI 的可用性是"工程 + 流程"养出来的，不是模型自带的**。同一个免费模型，在无约束时正确率 71%，在值域白名单 + 对比示例 + 只读防线之下达到 100%；同样的洞察生成，无核验流程时会把编造的同比增长率直接送进经营报告。把 AI 当"需要代码评审的初级同事"而不是"全自动分析师"，是本周最重要的实践认知。
